GRPO：同一道题，多份答案一起比较 ​

PPO 用价值模型估计预期回报。如果对同一道题多答几次，直接拿这些答案的平均分当基准呢？

GRPO（Group Relative Policy Optimization，组相对策略优化）用组内奖励构造优势，省去独立价值模型。 下面讲 DeepSeekMath 中的原始、最终结果奖励版本；后续实现可能调整归一化和 KL 设置。DeepSeekMath 论文

1. 先算优势：这份答案比同组好多少？ ​

对问题 x，用本轮采样策略 πold 生成 G 份回答 y1,…,yG，各自得到奖励 R1,…,RG。

组内均值、标准差写为：

μ=1G∑i=1GRis=1G∑i=1G(Ri−μ)2

优势则是：

A^i=Ri−μs+εnum

Ri−μ 表示高于或低于同组平均多少；除以标准差，让不同组的奖励尺度更可比。εnum 是实现中常用的小正数，用来避免除零；它不是后面的 PPO 裁剪参数。组内标准化

把四份答案代进去 ​

假设问题是“17 × 23 等于多少”，四份回答的最终正确性奖励为：

(R1,R2,R3,R4)=(1,0,0,0)

采用上面的总体标准差，忽略很小的数值稳定项：

μ=0.25,s=0.1875≈0.433(A^1,A^2,A^3,A^4)≈(1.732,−0.577,−0.577,−0.577)

这是教学例子：答对的回答获得正优势，其他回答获得负优势。实际实现若用不同标准差约定，数值略有区别，方向不变。

比较发生在同一题内，因此不用先学一个“这道题通常能得几分”的价值模型。但评分仍然需要：它可以来自奖励模型、答案规则或测试结果。

2. 让整段奖励参与 token 更新 ​

设第 i 份回答长度为 Ti，生成第 t 个 token 前的上下文为 hi,t=(x,yi,<t)。

在最终结果奖励版本中，同一回答的所有有效 token 使用同一个优势：

A^i,t=A^i

新策略与采样策略的概率比是：

ρi,t(θ)=πθ(yi,t∣hi,t)πold(yi,t∣hi,t)

然后构造类似 PPO 的裁剪项：

ρ¯i,t=clip(ρi,t,1−ϵ,1+ϵ)Ci,t(θ)=min{ρi,tA^i,ρ¯i,tA^i}

这里 ϵ 才是裁剪宽度。正优势倾向于提高这条回答中已采样 token 的概率，负优势倾向于降低；clip 与 min 限制在有利方向上过度改变概率的额外收益。原始策略目标

同一个结果优势传给整段 token，是粗粒度的信用分配。它不意味着一份答对的解答里，每一步推理都正确，也不意味着失败答案的每个 token 都错。

3. 核心损失：组平均、长度平均，再加 KL ​

采用梯度下降的写法，原始 GRPO 的采样损失可以拆成：

LGRPO(θ)=−E[1G∑i=1G1Ti∑t=1Ti(Ci,t(θ)−βki,t(θ))]

期望中的问题来自训练集，G 份回答来自本轮 πold。展开负号后：

LGRPO=−E[平均裁剪收益]+βE[平均 KL 估计]

因此，最小化损失有两件事：提高有利的策略收益，同时惩罚偏离参考模型。 更新时，组内优势和旧 log 概率固定，只对当前策略求梯度。DeepSeekMath 的损失结构

1G 是对同组回答平均，1Ti 是先对每份回答的 token 平均。后一项使每份回答在外层有相同权重，但也会引入长度相关的优化差异。后续方法和训练库可能使用全批 token 平均或固定长度归一化，不能把这些变体与原始公式混在一起。实现差异参考

KL 项怎么算？ ​

原文使用的 token 级估计可以写为：

ui,t=πref(yi,t∣hi,t)πθ(yi,t∣hi,t)ki,t=ui,t−log⁡ui,t−1

先记住方向：这是“参考概率除以当前概率”，与策略概率比 ρ 的方向不同。

当两者概率相同，u=1，这一项为 0；因为 log⁡u≤u−1，它对每个样本都非负。对当前策略下的 token 取期望时，它估计的是：

DKL(πθ(⋅∣h)∥πref(⋅∣h))

它是采样估计，不等于每条样本都计算了完整词表 KL。复用旧策略样本时，采样分布也会有差异。β 控制这一约束的权重；部分后续配置取 β=0，但本篇保留原始目标中的 KL 项。KL 估计与配置

4. 如果全对或者全错，会怎样？ ​

若四个奖励都是 1，或都是 0，组内奖励相同，Ri−μ=0。加入稳定项后：

A^i=0

于是这组的奖励驱动策略项没有有效梯度信号。多生成几遍，并不保证得到可学习的差异。 若保留 KL 项，它仍可能带来正则梯度，不能说整个损失完全不更新。

因此，题目难度、采样多样性和奖励设计都很重要。过难的问题可能全错，过易的问题可能全对，都会降低这类组内比较的有效性。

5. 从公式搭出一轮 GRPO ​

和 PPO 对照，最主要的变化就在“优势怎么来”：PPO 依赖价值估计与后续回报，GRPO 依赖同题回答的组内奖励。策略裁剪的思路仍然保留，只是不用再训练独立 critic。
