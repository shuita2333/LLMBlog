PPO：自己作答，再根据评分改进 ​

SFT 教模型模仿示范。PPO 则让模型自己作答，再根据反馈调整下一次的选择。

PPO（Proximal Policy Optimization，近端策略优化）的核心，是用优势加权的概率比训练策略，再通过裁剪限制过度更新的激励。 下文采用经典 RLHF 中的 PPO-Clip；PPO 本身也可用于游戏、机器人等任务。PPO 原始论文

公式稍多，但可以沿着这条线阅读：评分 → 优势 → 策略损失 → 价值损失。

1. 先认清四个角色 ​

设 x 是问题，yt 是回答的第 t 个 token，ht=(x,y<t) 是生成它之前的上下文。

角色记号干什么？
策略模型πθ生成回答，是主要训练对象
奖励模型Rϕ(x,y)给完整回答打分
价值模型Vω(ht)估计从当前上下文起还能得到多少回报
参考模型πref提供稳定的行为参照，通常冻结

还有 πold：本轮生成回答时的策略版本。它是策略的采样快照，不是另一位长期固定的老师。更新本批数据时它保持不变，下一轮采样再刷新。实现不一定保存一份完整模型，也可以缓存采样时的 log 概率。

奖励负责“实际考了几分”，价值负责“预计能考几分”；二者不能混用。RLHF-PPO 流程参考

2. 奖励从哪里来，KL 又为什么要减？ ​

如果先用人类偏好训练奖励模型，一条样本包含更受喜欢的 yw 和较不受喜欢的 yl。常见损失是：

LRM(ϕ)=−Elog⁡σ(Rϕ(x,yw)−Rϕ(x,yl))

最小化它，会让好答案获得更高的相对分数。这是奖励模型的预先训练，不是 PPO 的策略损失。经典 RLHF 后续通常冻结奖励模型。InstructGPT 论文

如果只追求 Rϕ，策略可能找到评分漏洞。因此加入对参考模型的 KL 约束。对从当前策略采样的完整回答，理想目标可以写为：

J(θ)=Ex,y∼πθ[Rϕ(x,y)−βlog⁡πθ(y∣x)πref(y∣x)]

其中 β>0 控制参考约束强度。对回答取期望时，log 概率比就是序列 KL；单条样本的 log 比值可以为负，KL 的期望才是非负的。

为了把整段评分送到 token 级训练中，下面采用“末尾评分 + 每步 KL 惩罚”：

rt=1[t=T]Rϕ(x,y)−βktkt=log⁡πold(yt∣ht)−log⁡πref(yt∣ht)

T 是回答长度。本轮先用采样策略计算奖励并固定它，再开展参数更新。参考模型惩罚的设计

3. 从“得几分”变成“比预期好多少” ​

有奖励还不够，同样得 5 分，对容易题和难题的意义不同。优势就是要减掉一个预期基准。

常见的 GAE（广义优势估计）先算一步预测误差：

δt=rt+γVold(ht+1)−Vold(ht)

再累加后面的误差：

A^t=∑l=0T−t(γλ)lδt+l

这里 Vold 是采样阶段的价值估计；真正终止后，下一状态价值设为 0。γ 是回报折扣，λ 控制后续误差传播多远以及偏差与方差的权衡。GAE 原始论文

直觉上，δt 问的是：“这一步奖励，加上下一步预计还能得到的回报，是否超过我之前的估计？”A^t 再把后续反馈带回来。

举一个简化的终止状态例子：此时 rt=5，Vold(ht)=3，终止后的价值为 0，那么 A^t=δt=2。结果比预期好，应该鼓励这个选择。

优势不等于奖励。 某个回答奖励为正，但低于预期，它的优势仍可能为负。

4. 核心损失：概率比、优势和裁剪 ​

先定义新策略相对采样策略的概率比：

ρt(θ)=πθ(yt∣ht)πold(yt∣ht)

如果 ρt>1，说明更新中的策略更愿意生成这个 token。把它与优势相乘：

ρt(θ)A^t

正优势时，我们希望这个量增大；负优势时，希望降低这个 token 的概率，使这个量变得不那么负。

PPO-Clip 再比较原始项与裁剪项。把裁剪后的概率比记为 ρ¯t：

ρ¯t=clip(ρt,1−ϵ,1+ϵ)Ct(θ)=min{ρtA^t,ρ¯tA^t}

论文常把这个目标写成“最大化”。若统一使用梯度下降，策略损失就是：

Lactor(θ)=−Et[Ct(θ)]

ϵ 是裁剪范围，Et 在这里表示采样批次中有效回答 token 的平均。更新时，旧 log 概率和优势都视为固定值。PPO 裁剪目标

为什么需要 min？算两次就明白 ​

设 ϵ=0.2：

情况原始项裁剪项min 之后
A^=2, ρ=1.532.42.4
A^=−2, ρ=0.5−1−1.6−1.6

第一行：好选择的概率涨得太多，继续涨不再获得额外目标收益。

第二行：坏选择的概率降得太多，继续降也不再获得额外收益。

反过来，如果更新把好选择的概率压低，或把坏选择的概率推高，原始项仍会惩罚这种变化。min 取的是比较保守的目标，不能直接用一个裁剪过的比值替代整条式子。

裁剪也不是硬性保证每个概率比都落在区间内。参数共享、其他 token 的梯度，都可能让某个比值继续变化。

5. 价值模型自己怎么学？ ​

价值模型也需要修正预估。可以用 GAE 对应的回报目标：

G^t=sg(A^t+Vold(ht))LV(ω)=12Et(Vω(ht)−G^t)2

sg 表示 stop-gradient：把目标当作常数，不让它跟着预测一起变化。构造 G^t 要用原始优势，不能先拿为了策略训练而归一化后的优势替换它。

一种常见的组合损失是：

Ltotal=Lactor+cVLV−cHEtH(πθ(⋅∣ht))

cV 控制价值损失权重；H 是熵，cH≥0 控制可选的探索奖励。策略与价值可以使用不同模型，也可以共享部分网络。PPO 的价值与熵项

本篇已经把参考 KL 放进 rt，再经优势进入策略损失；不要无意中把同一项又加一次。实际实现还可能使用价值裁剪、优势归一化等设置，它们属于额外选择。

6. 从公式搭出一轮 PPO ​

这样，原来的“答题后听评价”就被拆成了明确的计算：奖励提供方向，价值提供基准，优势分配学习信号，概率比利用本批样本，裁剪让策略更新更克制。
