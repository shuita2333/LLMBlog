SFT：跟着好答案学怎么回答 ​

一个模型已经会续写，为什么还要教它回答问题？因为“接着写得通顺”与“按你的要求作答”之间，还差一套示范。

SFT（Supervised Fine-Tuning，监督微调）把高质量问答变成训练样本，让模型提高示范答案的生成概率。 它也是 InstructGPT 后训练中的一个阶段。InstructGPT 论文

下面从损失函数出发，看看这句“提高概率”到底怎么做到。

1. 先把一条回答拆开 ​

假设有一条样本：

问题： 用一句话解释过拟合。
示范回答： 就像背熟了练习题，却不会做换了问法的新题。

统一记号：x 是问题，y=(y1,…,yT) 是回答的 token 序列，θ 是待训练参数。token 是模型处理文字的小单位，不一定等于一个汉字。

模型生成整段回答的概率可以拆为：

πθ(y∣x)=∏t=1Tπθ(yt∣x,y<t)

读成白话就是：先生成第一个 token，再基于它生成第二个，一直写到回答结束。y<t 表示当前 token 之前的回答前文。

取对数后，乘积变成加法：

log⁡πθ(y∣x)=∑t=1Tlog⁡πθ(yt∣x,y<t)

因此，不必直接处理整段文字的小概率乘积，可以累加每一步的 log-probability。

2. 核心损失：为什么是负对数概率？ ​

对一条示范，最基本的负对数似然损失是：

ℓSFT(x,y)=−∑t=1Tlog⁡πθ(yt∣x,y<t)

最小化前面的负号，等价于最大化示范答案的对数概率。 这正是语言模型交叉熵训练的核心。SFT 训练说明

先只看一个位置。假设目标 token 是“过”：

模型给“过”的概率单位置损失 −log⁡p
0.12.303
0.80.223

这里用自然对数。模型越不相信正确 token，损失越大；它把概率从 0.1 提到 0.8，这个位置的损失就明显降低。

加上 mask，才是问答微调常见的计算方式 ​

一批样本通常包含问题、回答和补齐长度的 padding。并非所有位置都要参与训练：

LSFT=−1N∑b=1B∑tmb,tlog⁡πθ(zb,t∣zb,<t)N=∑b,tmb,t

zb 是套好对话模板后的完整序列，mb,t∈{0,1} 是损失掩码，B 是批大小，N 是有效目标 token 数量。

常见的回答专用训练设置是：问题和 padding 的 mask 为 0，回答的 mask 为 1。这样模型能看到问题，但不会把“复述问题”也当成监督目标。多轮对话可以只监督 assistant 的位置；具体取决于训练配置。掩码配置参考

这里采用“有效 token 平均”。若改成“每条回答先平均，再对样本平均”，不同长度样本的权重会变，不能当成完全相同的损失。

3. 交叉熵怎么把正确 token 拉上去？ ​

设某个位置的模型输出为 logits uv，经 softmax 得到词表内各 token 的概率：

pv=euv∑j∈Veuj

V 是词表，v 是其中一个 token。若示范目标是 yt，目标分布就是“只有 yt 的概率为 1”的 one-hot 分布：

qv=1[v=yt]

交叉熵于是化为：

ℓt=−∑v∈Vqvlog⁡pv=−log⁡pyt

再对 logits 求导：

∂ℓt∂uv=pv−1[v=yt]

这一步把更新方向说清楚了：

  • 对目标 token，梯度是 pyt−1。梯度下降倾向于把它的 logit 拉高。
  • 对其他 token，梯度是 pv。梯度下降倾向于把它们的 logit 压低。

实际模型的参数是共享的，一次更新会影响很多位置。这条导数解释的是单个训练位置的直接监督方向，不是保证每个 token 的最终概率都单调变化。

4. 从公式搭出训练流程 ​

实现时有三个容易忽略的地方：

  1. 前文用示范。 预测“却”时，输入中它之前的文字来自标准答案，这叫 teacher forcing。
  2. 标签要移一位。 当前位置预测下一个 token。部分模型库内部已经做了移位，不能再手动重复移位。
  3. 可以并行训练。 因果注意力保证不偷看后文，因此一遍前向能计算多个位置；推理时才通常逐 token 生成。

SFT 的学习信号始终来自示范。它能教格式、语气和任务解法，也会把示范中的错误带进去。后面的 DPO 会加入答案之间的偏好，PPO 则让模型生成后再接收奖励。
