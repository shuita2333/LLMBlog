Transformer：跟着一个 token 看清整体结构 ​

第一次看 Transformer 结构图，最容易记住一串名字：Attention、FFN、Add & Norm。可一旦问“某个词在里面到底经历了什么”，这些名字又散了。

这篇沿着数据往前走：文字先变成向量，向量从上下文取信息，再做特征变换，最后变成下一 token 的概率。 同时区分原始 encoder–decoder Transformer 与常见的 decoder-only 语言模型，避免把两张结构图混为一谈。

1. Transformer 有三种常见组织方式 ​

原始 Transformer 为机器翻译设计，包含编码器和解码器。编码器读源句，解码器结合源句表示生成译文。原始论文

组织方式注意力如何看上下文？常见用途
Encoder-only通常双向看整段输入文本表示、分类、检索
Decoder-only通常只看当前位置及其之前自回归生成
Encoder–decoder编码输入；解码时再关注编码结果翻译、文本到文本任务

这里的“decoder-only”不表示直接保留原始解码器的全部模块。它通常没有读取独立编码器结果的 cross-attention，主要堆叠因果自注意力 + FFN。这些组织方式及其可见范围，也是 T5 研究比较的内容。架构比较

下面以一个采用 Pre-Norm 的 decoder-only 模型为主线。具体模型可能使用不同位置编码、归一化、激活和注意力头配置。

2. 输入：token ID 不是“第几个词” ​

分词器先把文字转成整数 ID。设词表大小为 V，隐藏宽度为 D，可学习的 embedding 表是：

E∈RV×D

token ID 用来查这张表，得到一行向量。对批大小 B、序列长度 L 的输入：

IDs:B×L⟶X(0):B×L×D

例如 B=2,L=8,D=512，就是两段文本，每段八个 token，每个 token 用 512 个数表示。

ID 表示“是哪种 token”，序列下标表示“它出现在哪里”。 同一个 token 在两个位置，查到的初始内容向量可以相同；顺序信息需要位置机制接入。

可学习绝对位置或正弦编码通常与 embedding 相加；RoPE 则通常作用于每层注意力里的 Q,K。因此，“所有 Transformer 都先加一张位置向量”是不准确的。位置编码详解

3. 一个 block：先交流，再加工 ​

一种常见的 Pre-Norm block 可以写成：

Y=X+Attn(Norm1(X))Z=Y+FFN(Norm2(Y))

X,Y,Z 的形状都保持 B×L×D。两个 Norm 一般是独立模块，可能采用 LayerNorm 或 RMSNorm。为看清主线，公式省略 dropout 等可选细节。Pre-Norm 分析

这两步的分工是：

  • 注意力： 当前 token 从其他可见位置读取信息。
  • FFN： 对已经融合上下文的向量，做非线性的特征加工。
  • 残差： 把原表示加回来，让子层学习如何修改它。
  • 归一化： 调整送入子层的特征尺度，帮助深层网络优化。

想象句子“杯子没放稳，它摔碎了”。模型对“它”的表示，可以通过注意力读取“杯子”和周围语境；FFN 再对融合后的特征进行变换。这个例子说明信息流，不代表某个固定头必然专门处理代词。

4. 注意力为什么能在 token 之间传信息？ ​

先忽略批维，把某层输入写成 X∈RL×D。通过三组投影得到：

Q=XWQ,K=XWK,Vval=XWV

这里 Vval 是 value 矩阵，与前面“词表大小 V”不同。Q 是查询，K 是匹配线索，value 是读取的内容。

单头注意力是：

A=softmaxrow(QK⊤dk+M)O=AVval

QK⊤ 给出“每个查询位置对每个候选位置”的分数，A 是 L×L 的权重矩阵。每一行做 softmax，再把候选位置的 value 加权混合。注意力机制

因果 mask 满足：

Mij={0,j≤i−∞,j>i

它禁止位置 i 读取未来的 j。padding mask 则解决“不要读取补齐位置”，两者用途不同。

多头版本使用多组投影，各自产生权重，再拼接并投影回 D 维。分数、缩放和多头维度会在多头注意力里展开。

5. FFN 是什么？为什么注意力后还要它？ ​

原始 Transformer 的 FFN 是：

FFN(x)=ReLU(xW1+b1)W2+b2W1∈RD×Dff,W2∈RDff×D

它先扩展特征维度，经过非线性，再压回 D 维。原始基本配置中，D=512,Dff=2048。FFN 结构

“position-wise”表示每个位置独立经过同一个 FFN：不同位置共享参数，但这一步没有直接混合 token 位置。 它处理的是注意力已经带来的上下文特征。

如果只串联两次线性变换，没有非线性，它们仍相当于一次线性变换。中间激活增加了表达能力。

现代模型还常用门控版本，例如 SwiGLU：

SwiGLU(x)=[SiLU(xWg)⊙(xWu)]WdSiLU(z)=zσ(z)

一条分支提供内容，另一条通过逐元素乘法控制内容通过多少。它有三个投影矩阵；为保持相近参数预算，中间宽度往往相应调整。这里省略偏置，具体以模型配置为准。GLU / SwiGLU 论文

6. 堆叠多层后，怎么得到下一个词？ ​

模型把 block 重复 N 次，但通常各层参数独立。后层使用前层已经融合过的表示，再进行下一轮上下文交互和特征加工。

设最后经过输出归一化的向量是 H：

H:B×L×D

语言模型头把它映射到词表：

logits=HWvocab+b,Wvocab∈RD×Vpb,t=softmax(logitsb,t)

logits 的形状变为 B×L×V。一个位置的输出分布，通常用来预测它之后的 token；LM head 与输入 embedding 也可能共享权重。

训练和推理为什么看起来不同？ ​

训练时，已有完整示范，输入前缀与目标错开一位。因果 mask 让各位置不能偷看后文，因此能并行计算多个预测位置。SFT 中的标签移位

推理时，没有未来的答案，通常每次生成一个新 token，再继续。KV cache 保存各层过去位置的 key、value，避免每一步重新计算全部历史。它不会让自回归生成变成一次性知道所有未来 token；后文仍依赖已生成的前文。

7. 原始 encoder–decoder 多了哪条路？ ​

编码器的自注意力通常双向读取源序列。原始解码器包含三类子层：

  1. 对目标前缀做 masked self-attention。
  2. 对编码器输出做 cross-attention。
  3. 对目标位置表示做 FFN。

cross-attention 的 Q 来自目标侧，K,V 来自编码器输出。如果目标长度是 Lt、源长度是 Ls，注意力权重是 Lt×Ls：每个译文位置在源句中找线索。

原始 Transformer 使用 Post-Norm，即 LN(X+F(X))；上面画的是常见 Pre-Norm 变体。两者位置不同，不能只因为都叫“Add & Norm”就混为一个公式。原始架构

8. 对照维度，检查你是否真的理解了 ​

阶段张量形状主要变化
token IDB×L文字变为索引
embeddingB×L×D索引变为内容向量
block 输入与输出B×L×D表示逐层更新
FFN 中间层B×L×Dff在特征维扩展
LM headB×L×V特征变为词表分数

注意力的额外开销主要来自位置之间的两两比较，普通实现的分数矩阵有 L2 项；FFN 的主要计算则来自每个位置的宽矩阵变换。模型不是只靠 Attention 工作，而是这些模块共同构成可训练的深层网络。
