位置编码：Transformer 怎样知道顺序和距离？ ​

“小猫追小狗”与“小狗追小猫”，词差不多，意思却不一样。模型需要知道谁先出现、谁后出现，以及两个 token 相隔多远。

位置编码就是给表示或注意力补充这种信息。它不一定是一组加在 embedding 上的向量，也可以改变注意力分数，或者旋转 query 与 key。

1. 没有位置机制，注意力缺了什么？ ​

先限定条件：全可见自注意力、没有位置编码、没有与位置有关的 mask，各位置共享投影和 FFN。

设 P 是重排序列的置换矩阵，那么这种网络满足：

F(PX)=PF(X)

这叫置换等变：交换输入行，只会相应交换输出行。它不是“输出完全不变”，而是每个内容 token 缺少固定的顺序标识。

原因可以沿着注意力公式看：输入重排后，Q,K,V 都按同样方式重排，注意力矩阵的行和列随之一起重排。单个 token 仍面对同一组内容，无法仅靠这套运算辨认谁位于它前面。

原始 Transformer 因此在输入加入位置编码。原始位置设计

有因果 mask 时，情况并不完全相同：各位置可见的前缀长度不同，mask 已破坏上述对称性，并带来部分顺序线索。所以不能笼统说“无显式位置编码的任何 Transformer 都绝对不知道顺序”。 但因果可见范围与丰富的位置、距离表示仍是不同机制。

2. 先区分绝对位置与相对位置 ​

类型关心的问题常见接入点
绝对位置这个 token 在第几个位置？输入 embedding
相对位置两个 token 相隔多远、方向如何？注意力分数或相关向量
旋转位置机制让两位置的旋转关系影响匹配每层的 Q,K

例如，当前位置是第 20 个 token，另一个在第 17 个位置：

  • 绝对信息是“20”和“17”。
  • 相对信息是“它在我之前 3 个位置”。

相对机制可以更直接表达局部关系，但并不自动保证任意长度都能泛化。下面逐种展开。

3. 正弦位置编码：不同频率的刻度尺 ​

原始 Transformer 的正弦编码为：

PE(p,2i)=sin⁡(p100002i/D)PE(p,2i+1)=cos⁡(p100002i/D)

p 是从 0 起的位置，D 是表示宽度，i 是正弦、余弦维度对的编号。输入通常写成：

Xp=Etoken(p)+PE(p)

每一对维度使用一种频率。有的随位置变化快，有的变化慢，合起来给位置提供多尺度信号。

举 D=4 的教学例子，位置 0 与 1 的编码约为：

PE(0)=[0,1,0,1]PE(1)≈[0.8415,0.5403,0.0100,0.99995]

后两维变化慢，因为它们使用更低的角频率。它不是给每个位置分配一个独立 ID，而是用连续函数产生位置特征。

为什么它也能表达相对位移？ ​

对固定的位移 k，有三角恒等式：

sin⁡((p+k)ω)=sin⁡(pω)cos⁡(kω)+cos⁡(pω)sin⁡(kω)

所以位置 p+k 的一对特征，可以由位置 p 的特征经一个与 k 有关的线性变换得到。这为学习位移关系提供了结构。

正弦公式能在训练长度之外继续计算；能算出来，不等于模型已经学会正确利用未见过的长距离。 无需学习位置参数，也是它的一个特点。正弦编码及设计理由

4. 可学习绝对位置：让模型自己学刻度 ​

另一种方式直接学习一张位置表：

Pemb∈RLmax×DXp=Etoken(p)+Pemb[p]

第 p 行是位置 p 的可学习向量。它与 token embedding 类似，只是一个按“内容 ID”查表，一个按“位置下标”查表。

优点是位置特征可随任务调整，实现也直接。限制是：

  • 位置表有额外参数。
  • 超过表的长度，没有现成的对应行。
  • 即使给表增加新行，未训练的位置也不会自动获得可靠含义。

插值、扩展并继续训练可以处理这些问题，但这是额外设计，不是原表天然拥有的能力。原始 Transformer 也实验了可学习位置向量。原论文实验

5. 相对位置：直接改“我与它”的匹配 ​

Shaw 等人的方法把相对位置向量加入注意力匹配。例如：

sij=qi⊤(kj+aijK)dk

aijK 由两个位置的相对距离决定，原方法也讨论了 value 侧的相对表示。于是，内容匹配与距离关系共同决定权重。Shaw 相对位置论文

还有更轻量的相对偏置形式：

sij=qi⊤kjdk+bbucket(i−j)

它直接在分数上加一个可学习偏置。T5 使用分桶的相对位置偏置：近距离可以区分得更细，远距离则合并到较粗的桶中。T5 相对偏置

这相当于给匹配分数加上一条先验：“这个距离值得多关注一些吗？”但内容分数仍在，不是只按距离选 token。

分桶或截断能减少参数、处理更多距离，但也会降低某些远距离的区分精度。

6. RoPE：把位置变成旋转角度 ​

RoPE（Rotary Position Embedding）通常不把位置向量加到输入上，而是把每个 head 的 Q,K 特征两两分组，按位置旋转。RoFormer 论文

对一个二维特征对，定义旋转矩阵：

R(α)=[cos⁡α−sin⁡αsin⁡αcos⁡α]

在位置 m,n 上：

q~m=R(mω)qm,k~n=R(nω)kn

点积就变成：

q~m⊤k~n=qm⊤R((n−m)ω)kn

这条等式是 RoPE 的核心：虽然旋转分别使用绝对位置，最终匹配里的旋转关系只取决于相对位移 n−m。

例如，把两个位置同时向后平移 10，旋转造成的相对角度不变。注意，这说的是固定内容向量下的匹配结构，不代表整个模型在任何上下文平移下都完全不变。

对维度为 dh 的 head，原始频率通常写为：

ωr=10000−2r/dh

不同维度对仍然对应不同频率。旋转保持向量长度，但改变方向，从而改变点积。典型用法只旋转 Q,K，不旋转 value；具体变体可能不同。

7. ALiBi：距离越远，先扣一点分 ​

ALiBi（Attention with Linear Biases）采用更直接的距离偏置。因果注意力中，对于 j≤i：

sij(h)=qi⊤kjdh−mh(i−j)

mh>0 是第 h 个 head 的斜率。距离越远，减掉的分越多；不同 head 使用不同斜率。未来位置仍要单独用因果 mask 屏蔽。ALiBi 论文

设某个 head 的 mh=0.1，距离分别为 1 和 10，偏置就是 −0.1 与 −1.0。内容分数一样时，更近的 token 获得更高权重；内容匹配特别强时，远处 token 仍可能被关注。

这种机制无需给每个绝对位置学习一行向量。论文展示了长度外推的优势，但不能据此断言它对所有任务、所有长度都优于 RoPE。

8. RoPE 能计算更长位置，为何还需要扩展技术？ ​

超过训练长度后，模型会遇到未学过的位置相位组合、距离和注意力分布。于是出现位置插值等方法：

p′=p/α,α>1

它把较长序列的位置压进较小范围。代价是相邻 token 的位置差也被压缩，可能影响原来的局部关系，需要合适的训练或适配。Position Interpolation

YaRN 等方案会进一步调整不同频段的处理及注意力尺度，兼顾局部距离与长上下文。YaRN 论文

因此要分清三件事：公式支持某个位置、模型在该长度下经过训练、模型在该长度下仍能可靠检索与推理。 它们并不等价。长上下文还受到计算、缓存和训练数据的约束。

9. 把这些技术放在一张表里 ​

技术改哪里？主要思路需要留意
正弦绝对位置输入向量固定多频率刻度可计算不等于可靠外推
可学习绝对位置输入向量学习各位置的表示表长与未训练位置
相对位置向量 / 偏置注意力匹配显式建模相对距离截断、分桶精度
RoPEQ,K旋转差体现相对位移长距离相位与适配
ALiBi注意力分数线性距离惩罚距离先验与任务差异

阅读模型代码时，找位置机制最有效的办法不是只搜“embedding”：还要检查 Q,K 是否被旋转，以及 softmax 前的注意力分数是否加入了距离偏置。
