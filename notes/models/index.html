怎样读这片森林 ​

  • 共用年月纵轴。 主图默认显示全部已收录厂商的 2026 年产品；可用厂商按钮缩小比较范围，横向滚动查看全部主线。小节点展示代表模型和当月发布数量，悬停可看完整模型名单。每个月占相同高度，即使没有收录发布也保留主线。连线表示时间关系，不代表模型训练血缘。
  • 涵盖 LLM 及相关模型。 语言、推理、代码、视觉理解、语音、图像与音视频生成、文档 OCR、Embedding / Reranker、端侧和 3D 世界模型均可纳入。相关生成模型不自动等同聊天 LLM。
  • 按事件和证据精度记录。 优先采用官方发布日；服务、API、权重开放、预览和论文公开不是同一事件。月份节点不推断具体日，只有年份的节点单列。日期字符串采用来源口径，不做跨时区小时级排序。
  • 点击后读完整脉络。 节点展示该厂商当月的发布，详情窗口始终保留该厂商全部历史，不受主图搜索、年份或能力筛选影响。技术改进概括来自厂商公告、模型卡或技术报告；不是独立复现实验。参数量、窗口和任务成绩不能直接跨模型排名，Agent 工具编排也不能全部归因于底座。
  • ✦ 是选题线索。 表示有可单独展开的技术问题，尚未写成独立模型博客。这里先建立地图，再选择值得深入的节点。

收录范围与更新 ​

这是持续维护的主流厂商与关键节点精选，不是所有 API 快照、量化版本和地区入口的穷尽目录。优先记录有官方证据、技术转折或能力分支变化的发布；没有可靠一手来源的传闻暂不入树。单一品牌名与 API 名合并展示，避免重复计数。

新节点更新后会自动参与日期排序、筛选和统计，不需要重画树。历史记录保留发布时的技术信息，可用状态按最后一次核验说明；当前价格和额度请查厂商文档。主图底部提供厂商完整历史入口；详情中的历史起点是本页精选范围，不代表厂商成立时间或首个模型。
