DQN 深度 Q 网络详解：神经网络如何学会玩游戏

发表于2026-08-27|更新于2026-08-27|模型训练

如果把强化学习智能体放进一个游戏，它不会收到“这一帧应该按左键”的标准答案。它只能不断尝试动作，看到分数增加还是角色死亡，再逐渐摸索出有效策略。

传统 Q-Learning 可以用一张表记录每个状态下各个动作的价值，但游戏画面包含成千上万个像素，可能的状态几乎无穷无尽，表格根本存不下。DQN 的核心想法因此非常直接：用神经网络代替 Q 表，根据当前状态预测每个动作的价值。

DQN 全称 Deep Q-Network。2013 年，DeepMind 展示了仅从屏幕像素学习 Atari 游戏的初步结果；2015 年发表于 Nature 的工作进一步表明，同一套算法可以在多种 Atari 游戏上从像素和得分中学习策略。DQN 也由此成为深度强化学习最经典的入门算法之一。

先认识强化学习问题

智能体与环境不断进行如下交互：

  1. 在时刻 观察状态 ；
  2. 根据策略选择动作 ；
  3. 环境返回奖励 和下一状态 ；
  4. 重复交互，直到回合结束。

其中折扣因子 。 越接近 0，智能体越看重眼前收益；越接近 1，就越愿意为长期回报暂时付出代价。

例如，游戏角色向右走一步可能没有奖励，但连续向右最终能拿到宝箱。只追逐即时奖励的智能体很难学会这种延迟满足。

直接训练为什么容易失败

把神经网络生硬地接到 Q-Learning 上，训练通常很不稳定，主要有两个原因。

第一，相邻交互样本高度相关。游戏的连续两帧几乎相同，而随机梯度下降通常希望每个 mini-batch 中的样本相对独立。如果网络连续学习一长串相似画面，很容易过拟合最近的经历，并遗忘更早的状态。

第二，训练目标本身也在快速变化。如果同一个网络既负责预测 ，又负责计算目标中的 ，参数每更新一次，预测值和学习目标就会一起移动，形成“追逐自己的影子”的局面。

DQN 用两个关键设计缓解这两个问题：经验回放与目标网络。

经验回放：打乱时间相关性

智能体将每一步转移保存进回放缓冲区：

训练时不只使用最新一步，而是从 中随机采样一个 mini-batch。这样做有三个好处：

  • 打散连续样本之间的时间相关性；
  • 一条经验可以被重复利用，提高样本效率；
  • mini-batch 同时包含不同时期、不同场景的数据，减轻策略快速变化带来的分布波动。

缓冲区通常设定最大容量，装满后覆盖最旧数据。最基础的 DQN 使用均匀采样，后续的优先经验回放则让 TD error 较大的样本更容易被抽中。

DQN 维护两个结构相同的网络：

  • 在线网络 ：负责选择动作并通过梯度下降持续更新；
  • 目标网络 ：负责计算 TD target，在一段时间内保持冻结。

一轮 DQN 训练如何进行

完整流程可以概括为：

  1. 初始化在线网络、目标网络和经验回放缓冲区；
  2. 将在线网络参数复制给目标网络；
  3. 根据 -greedy 策略与环境交互；
  4. 把 存入回放缓冲区；
  5. 随机采样一个 mini-batch；
  6. 用目标网络计算 TD target；
  7. 只对在线网络反向传播并更新参数；
  8. 定期同步目标网络，直到训练结束。

DQN 是 off-policy 算法

DQN 学习的是最优动作价值，其中 target 使用 ，与收集数据时实际采用的 -greedy 行为不必完全一致。因此，DQN 属于 off-policy 方法。

这也解释了经验回放为什么可行：缓冲区中既有旧策略产生的数据，也有大量随机探索数据，DQN 仍然可以使用它们学习贪心目标策略。相比必须频繁丢弃旧样本的 on-policy 方法，DQN 通常具有更高的样本复用率。

常见扩展

DQN 之后出现了许多重要改进：

方法 主要解决什么问题
Double DQN 减轻 max 导致的价值过估计
Dueling DQN 分别估计状态价值与动作优势，更高效地判断状态好坏
Prioritized Replay 优先学习 TD error 较大的关键经验
Multi-step Return 让奖励更快地向前传播
Noisy Network 用可学习参数噪声替代手工 探索
Distributional DQN 学习回报分布，而不只学习期望值
Rainbow 将多种有效改进组合到同一个智能体中

这些方法没有推翻 DQN 的基本框架，核心仍然是价值估计、Bellman target、经验回放和相对稳定的目标网络。

训练时应该监控什么

只看 loss 很容易误判。DQN 的 target 本身不断变化，loss 下降不一定意味着策略变好，loss 暂时上升也可能只是智能体探索到了新的高奖励区域。更有意义的指标包括：

  • 多个评估回合的平均回报与方差；
  • 平均 Q 值和最大 Q 值是否持续爆炸；
  • TD error 的分布；
  • 回放缓冲区大小与样本多样性；
  • 探索率 的变化；
  • 回合长度、成功率等任务指标。

评估时应关闭随机探索，并使用与训练不同的随机种子。强化学习结果方差很大，只运行一次得到的漂亮曲线并不能证明算法稳定。

常见问题与排查方向

奖励一直没有提升

先确认状态、动作和终止标记是否正确，再检查探索率是否衰减过快。奖励非常稀疏时，普通随机探索可能几乎碰不到成功轨迹，需要奖励塑形、更好的探索方法或示范数据。

Q 值越来越大

可能原因包括终止状态没有屏蔽 bootstrap、奖励尺度过大、学习率过高、目标网络更新太快，以及原始 DQN 的过估计。可以依次检查 done 处理、奖励裁剪、梯度裁剪和 Double DQN。

loss 在震荡

一定程度的震荡是正常现象，因为数据分布和 TD target 都不固定。如果同时伴随回报下降，应检查回放缓冲区是否太小、batch 是否相关、目标同步频率是否合适，以及输入是否完成归一化。

学到的策略无法复现

除了设置 Python、NumPy、PyTorch 和环境的随机种子，还要保存网络参数、优化器状态、训练步数和探索率。完全确定性的强化学习训练通常很难保证，因此应报告多个随机种子的均值与标准差。

DQN 的适用范围与局限

DQN 最适合状态维度较高、动作数量有限且离散的任务，例如 Atari 游戏、离散调度或小规模控制问题。

它也有明确边界：

  • max 需要枚举动作，不适合高维连续动作空间；
  • 对超参数、奖励尺度和随机种子较敏感；
  • 随机探索在稀疏奖励任务中效率很低；
  • 回放缓冲区需要额外内存；
  • 神经网络、bootstrap 与 off-policy 数据同时出现时，仍可能发生不稳定甚至发散。

连续动作任务通常会考虑 DDPG、TD3 或 SAC；如果更适合直接优化策略，也可以使用 PPO 等策略梯度方法。

DQN 与 PPO 的区别

对比项 DQN PPO
学习对象 动作价值 参数化策略 ，通常还学习价值函数
动作空间 主要用于离散动作 可用于离散或连续动作
数据策略 Off-policy，可复用旧经验 On-policy，数据需要接近当前策略
动作选择 对 Q 值取 argmax 从策略分布采样或取确定性动作
稳定机制 经验回放、目标网络 概率比值裁剪、优势估计

两者都使用神经网络和 bootstrap 价值估计，但解决问题的方式不同。DQN 先学习“每个动作值多少”，再隐式得到策略；PPO 则直接调整动作概率，使高优势动作更常出现。

用一句话总结

DQN 就是：用神经网络近似 Q 函数，用 Bellman 方程构造学习目标，再通过经验回放打散数据、目标网络稳定目标、-greedy 保持探索。

理解 DQN 时，最关键的不是记住网络层数，而是分清三个角色：在线网络给当前动作估值，目标网络提供相对稳定的监督信号，经验回放负责把交互轨迹变成可重复采样的训练数据。
